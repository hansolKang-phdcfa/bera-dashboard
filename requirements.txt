# WHY 3.12: Streamlit Cloud briefly ran this app on Python 3.14, where the
# native stack (numpy/pandas/pyarrow C extensions) SEGFAULTS at startup —
# even with prebuilt 3.14 wheels. Cloud ignores .python-version, so the only
# fix is to delete + redeploy selecting Python 3.12. On 3.12 these pinned
# versions install as wheels and run clean (verified with streamlit AppTest).

# newer pyarrow (25.x) is built for the numpy 2.x ABI — mixing it with
# numpy 1.26.4 SEGFAULTS mid-render. pyarrow 20.0.0 matches numpy 1.x.
# Do NOT loosen to >= and do NOT redeploy on Python 3.13/3.14.
